# Certification Badges Folder

Place your certification badge images in this folder.

### Naming Convention:
Name the image file exactly after the certification code/title in lowercase, with no spaces and removing special characters (like colons or spaces).
For example:
- Certification "ISO 27001:2022" -> save as `iso27001.png` or `iso27001.svg`
- Certification "SOC 2 TYPE II" -> save as `soc2.png` or `soc2.svg`
- Certification "PCI-DSS v4.0" -> save as `pci.png` or `pci.svg`
- Certification "NIST CSF 2.0" -> save as `nist.png` or `nist.svg`
- Certification "HIPAA COMPLIANT" -> save as `hipaa.png` or `hipaa.svg`

Supported extensions: `.png`, `.svg`, `.jpg`, `.jpeg`, `.webp`
If an image is not found in this folder, the website will automatically fall back to loading the official badge logo.
