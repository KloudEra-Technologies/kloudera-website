# Partner Logos Folder

Place your partner logo images in this folder. 

### Naming Convention:
Name the image file exactly after the partner's name in lowercase, with no spaces.
For example:
- Partner name "Microsoft" -> save as `microsoft.png` or `microsoft.svg`
- Partner name "MongoDB" -> save as `mongodb.png` or `mongodb.svg`
- Partner name "AWS (Amazon Web Services)" -> save as `aws.png` or `aws.svg`
- Partner name "Google Cloud" -> save as `googlecloud.png` or `googlecloud.svg`
- Partner name "Fortinet" -> save as `fortinet.png` or `fortinet.svg`
- Partner name "Trend Micro" -> save as `trendmicro.png` or `trendmicro.svg`

Supported extensions: `.png`, `.svg`, `.jpg`, `.jpeg`, `.webp`
If an image is not found in this folder, the website will automatically fall back to loading the official corporate logo.
